# INF1007-PR02

## Descriptin du projet
Ce projet vise à la prédiction de lettres faites en langage des signes en temps réel grâce à un modèle d'appentissage automatique.

## Procédure d'installation:

Installer les packages nécessaires:

```bash
pip install -r requirements.txt
```

## Procédure de lancement

À partir du fichier du projet INF1007-PR02/src, lancez le fichier main.py. Ouvrez le lien généré dans votre terminal pour executer un localhost.

## Précision des modèles

Forêt aléatoire : 72%
Histogram gradient boosting : 69%
Regression logistique : 84%
